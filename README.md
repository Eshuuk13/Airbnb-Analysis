# 🏠 Airbnb Data Analysis & Demand Prediction Project

## 📌 Project Overview

This project analyzes Airbnb listing data to uncover pricing trends,
location performance, and customer demand patterns. It follows a
complete data analytics workflow including cleaning, EDA, visualization,
and a demand prediction model.

## 📊 Key Objectives

-   Analyze pricing by neighbourhood and room type\
-   Identify high-performing locations\
-   Understand demand patterns\
-   Build a booking demand prediction model

## 📈 Key Insights

-   Prices vary significantly by location and room type\
-   Entire homes earn higher average prices\
-   Flexible minimum nights attract higher demand\
-   Availability reflects booking behavior

## 🤖 Demand Model

Random Forest classifier predicting high vs low demand with \~86%
accuracy using pricing and availability features.
